# TIMELINES Studio - frontend

Next.js (App Router) + TypeScript + Tailwind CSS v4 dashboard for the local FastAPI backend.
The UI is a fully static export (`output: "export"`): every page is client-side and fetches JSON from `/api/...` on the same origin.
The HTTP contract is `../docs/API.md`; artifact types in `lib/types.ts` mirror `../backend/timelines/schemas.py`.

## Commands

```bash
npm install
npm run build        # static export -> frontend/out (served by the backend at "/")
npx tsc --noEmit     # type check

# Development with a separately running backend (CORS must allow http://localhost:3000, or use a proxy):
NEXT_PUBLIC_API_BASE=http://127.0.0.1:8790 npm run dev          # bash
$env:NEXT_PUBLIC_API_BASE="http://127.0.0.1:8790"; npm run dev  # PowerShell
```

`NEXT_PUBLIC_API_BASE` defaults to `""` (same origin). It is applied to `/api/*` calls and to media URLs (`/files/...`, `/assets-files/...`).

## Routing

Static export with `trailingSlash: true`: `/ideas/`, `/research/`, ... Project detail uses a query string, `/project/?id=<project id>`
(`useSearchParams` inside `Suspense`). The project selected in the top bar is stored in `localStorage` (`timelines.projectId`, wrapped in try/catch).

## Structure

```
app/                 pages (one folder per sidebar item + project/)
components/ui/       Button, Card, Badge, Tooltip, Tabs, Input/Textarea/Select/Label, Dialog,
                     Collapsible, Progress, Table - hand-written
components/common.tsx   state/stage/job chips, ProjectPage wrapper, ArtifactBoundary, JsonEditor, JobRow ...
components/scene-list.tsx  shared scene cards (Storyboard / Maps / 3D Studio)
components/shell/    app shell: icon sidebar with tooltips, top bar, jobs drawer
lib/api.ts           typed API client (ApiError with 422 validation details)
lib/hooks.tsx        AppProvider (projects, selected project, jobs polling), useAsync, useAction
lib/types.ts         TypeScript types for API objects and artifacts
```

## Notes

- The `components/ui/*` files follow shadcn/ui conventions (class-variance style variants, `cn()` helper, forwardRef primitives)
  but were written by hand; they were **not generated by the shadcn CLI**. No Radix packages are used.
- Jobs are polled every 2 s while any job is queued/running, every 10 s otherwise (`AppProvider`). Pages refetch their data when a job finishes.
- No sample or mock data exists in the app. Missing artifacts (404) show an empty state; failures show the backend's `detail`.
- Automatic QC and generated media are never presented as human approval.
